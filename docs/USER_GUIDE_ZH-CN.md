## 1. 首页：先看懂 3.0 首页

3.0 首页是轻量首页，分 8 个区（sections），第一屏只显示最关键的状态，
不把所有诊断卡一次全渲染出来：

- **设备概况**：机型、系统版本、读取状态。
- **待应用更改**：当前已暂存、尚未应用的更改数量。数字为 0 时表示没有
  未应用的更改。
- **常用功能**：快捷入口，可按第 12 节调整顺序。
- **诊断摘要**：11 张诊断卡的摘要在二级页面，点进去再看详情（诊断缓存
  会把文件读取与 SHA-256 移出渲染路径，首页打开更快）。
- **一键解锁入口、备份入口、全部工具入口**：分别进对应页面。

> 旧版工具页仍可从「全部工具」进入，确保功能可回退。

## 2. 第 1 步：读取设备

每次打开 App、每次改动前，都先做这一步：

1. 点首页的 **Read Device**（读取设备）。
2. 等读取完成。读取进度由真实读取状态驱动；上游读取路径不输出数字进度，
   因此 App 不会凭空显示百分比——看到的一直是“正在读取”而不是假的 37%。
3. 读取完成后首页显示设备概况；**China Unlock** 页显示 10 项的当前状态。

**读取失败怎么办：**

- 先确认系统是 iOS / iPadOS 27.x。26.x 上本机访问本来就不支持。
- 点首页的「重新读取」再试一次。
- 仍失败：不要应用任何改动，先看
  [TROUBLESHOOTING_ZH-CN.md](TROUBLESHOOTING_ZH-CN.md)。

## 3. 第 2 步：看懂 8 状态兼容性标识

每个功能旁边都有一个 8 状态统一兼容性模型的状态（`CompatibilityStatus`，
源码 `GestaltX/CompatibilityStatus.swift`）：

| 状态 | 含义 | 你该怎么做 |
| --- | --- | --- |
| 原生支持 Natively supported | 设备本身就支持，不用改 | 不用动 |
| 可改 Modifiable | 可以改，改了可能生效 | 按需暂存 |
| 已启用 Enabled | 开关已是开着 | 不用动 |
| 已暂存 Staged | 已暂存，还没应用 | 去确认页核对后应用 |
| 需重启 Needs restart | 已应用，重启后才生效 | 冷重启设备 |
| 未验证 Unverified | 无法确认是否可用 | 谨慎，先看详情里的设备要求 |
| 不支持 Unsupported | 设备 / 系统不支持 | 不要强行改 |
| 读取失败 Read failed | 读不到当前值 | 先解决读取问题，不要改 |

**关键提醒：** “可改”不等于“改了一定能用”。改的是能力标记（capability
flag），功能最终能不能跑，还要看硬件、系统版本与苹果服务。

## 4. 一键解锁：10 项暂存 → 确认 → 应用

一键解锁一次暂存 10 项：

- eSIM 两项开关：`green-tea` → 关（`false`）、`not-green-tea` → 开（`true`）
  （CacheData 槽位 #383 / #506）；
- 地区码：`RegionCode` → `LL`（美国，销售地区后缀不动）；
- 7 项 Apple Intelligence 能力：Apple 智能、Siri AI 模式、音频智能、个人翻译、照片消除、
  手写合成、常听 Hey Siri。

**操作流程：**

1. 打开 **China Unlock**，看 10 项的当前状态。
2. 点一键暂存，逐项核对 Diff 预览（改前值 → 改后值）。
   - **eSIM 缓存布局校验不通过时，整组会停住并显示原因。** 这是保护机制：
     布局对不上就强行写可能写坏缓存。此时不要绕过，地区码与 AI 仍可单独设置。
3. 确认无误后点应用。应用过程依次是：自动备份 → 写入 → 写回校验 → 完成。
   每一步都是真实操作的状态，不是写死的动画。
4. 应用完成后**冷重启**：滑动关机，等黑屏后再开机。只刷新 SpringBoard
   对 eSIM 不够。
5. 开机后去系统「设置」检查 eSIM 与 Apple Intelligence。
6. 想全部撤销：用一键还原，从备份恢复全部 10 项（含义与限度见
   [BACKUP_RESTORE_ZH-CN.md](BACKUP_RESTORE_ZH-CN.md)）。

**地区码与销售地区：**

- 通常只改地区码就够了，不用改销售地区。
- “地区代码”选“美国”时仅将 `RegionCode` 设为 `LL`，保留销售地区后缀；
  也可选中国大陆、香港、台湾、日本或英国。
- 销售地区与地区代码可以一起应用：后缀按销售地区设置，代码按地区代码设置。
- 之前改过销售地区的用户：请先改回设备原本的销售地区并应用。

## 5. 功能目录：53 项，11 个分类

功能目录（`FeatureCatalog`，源码 `GestaltX/FeatureCatalog.swift`）共 53 项：
40 个预设项 + 13 个页面项，分 11 类：

1. 智能解锁（smartUnlock）
2. Apple 智能（appleIntelligence）
3. eSIM 与地区（esimRegion）
4. 屏幕与锁定（screenLock）
5. 系统设置（systemSettings）
6. 个性化（personalization）
7. 启动图（launchArtwork）
8. 设备诊断（deviceDiagnostics）
9. 已改记录（modifiedRecords）
10. 备份与还原（backupRestore）
11. 高级工具（advancedTools）

每个功能名下都有一句简体中文用途说明；设备要求与生效方式放在详情里。
完整清单见 [FEATURES_ZH-CN.md](FEATURES_ZH-CN.md)。

排序规则统一：版本化 JSON + SHA-256 sidecar，预设只按一个顺序排，
不会出现不同页面顺序打架的情况。

## 6. 单个预设：改、停用、还原

- **改一项：** 打开该预设，确认说明与设备要求，暂存后在确认页核对前后
  对比值，再应用。
- **停用一项：** 关掉预设开关，或点该项的“还原”，会恢复已记录的原值及类型；
  原本不存在的字段会被删除。
- **旧版改过、没有原值记录：** 仅对确认是后来添加的字段使用“移除新增字段”。
- **InternalBuild（系统全局内部标记）：** 开启前有单独确认，请想清楚再点。
  这是系统级标记，乱开可能导致系统行为异常。

## 7. MG 控制：直接改字段

**MG 控制**（MG Control）是字段编辑器，直接读写 `CacheExtra`：

- 读取、搜索、添加、编辑、删除字段；
- 支持 String、Integer、Real、Boolean、Data、Date、Array、Dictionary；
- 改动同样走暂存 → 确认 → 应用 → 备份 → 写回校验的流程。

**注意：**

- 预设页显示的是上次读取的快照，MG 控制显示的是 CacheExtra 实时值。
  两边对不上时，先点首页「重新读取」。
- `RegionCode` 与 AI 各项是 CacheExtra 的键，能搜到；`green-tea` /
  `not-green-tea` 是 CacheData 槽位（#383 / #506），**搜不到**，请走 eSIM 预设。
- **不要改机型标识（`ProductType`）。** 把国行主板强改成美版会让基带校验
  失配，eSIM 菜单整个消失。

## 8. 备份与还原

- 首次读取时自动备份；每次写入前自动备份；每次备份记录原值。
- 备份页可以打开、导出、恢复、删除备份。
- 还原只会写回 App 自己记录的原值；**“恢复记录的原值”≠“真正的出厂状态”**。
  如果某值在 App 第一次备份前就被改过，备份里存的就是改过之后的值。
- 卸载 App 会删掉容器内的备份（出厂金库除外），重装 / 证书过期前务必先导出。
- 完整说明见 [BACKUP_RESTORE_ZH-CN.md](BACKUP_RESTORE_ZH-CN.md)。

## 9. 导入 plist

1. 在“文件”或其他 App 中选中 MobileGestalt plist，点**分享**，选 **LilaShift**。
2. 分享扩展经共同的 App Group 把文件交给主应用；如未自动打开，请返回 LilaShift。
3. App 会核验：GestaltX 导出文件的本机凭证，或文件中至少两个唯一设备标识
   与本机信息比对；通过后弹窗确认导入。**无法核验的文件一律拒绝。**
4. 部分原始 plist 不含唯一设备标识：请先在本机用 LilaShift 导出一份副本。
   校验密钥只保存在本机钥匙串，不随文件导出。
5. 确认导入的文件作为本地文档打开，可在 MG 控制里编辑。
6. 点“**恢复导入的 plist**”可把已核验的文件恢复到本机：会核对系统缓存布局，
   经过二次确认后先备份当前文件，再写入并验证。完成后请重启设备。

## 10. 日志与重启

- **日志页**显示的是实际漏洞利用过程日志（`worse_query` 各阶段），可分享导出。
  报 Bug 时可附上脱敏后的日志片段（不要贴含个人标识的内容）。
- **重启：** 本版没有自动注销（respring）功能——NeoSpring 实现已因许可证
  原因移除。应用改动后请按 App 提示**手动重启设备**（冷重启）。

## 11. 个性化：壁纸、锁屏文字、启动图

- **壁纸设置：** 导入、添加、移除壁纸包，支持 `.tendies` 与 `.zip` 导入
  （可经分享扩展导入）。
- **锁屏文字：** 自定义锁屏底部文字，即时生效，无需重启设备。
- **App 启动图：** 自选照片、将当前启动图以原尺寸保存到相册、自动备份和还原。
- 以上功能均走同一套暂存 / 备份流程；改动前同样会自动备份。

## 12. 首页排序：调整快捷入口顺序

- 首页快捷入口支持系统原生重新排序（长按拖动）。
- 顺序保存在本机；旧版或异常排序数据会被自动修复。
- 首页 8 个区中，第 3–8 区（带跳转目标的区）随快捷入口排序一起调整。
