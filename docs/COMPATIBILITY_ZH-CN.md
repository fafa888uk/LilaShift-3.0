# 5.0.0 兼容性及真机验收

| 环境 | 亮度读取／写入／恢复 | 实测状态 |
| --- | --- | --- |
| 具有内置屏幕的 iPhone/iPad、iOS/iPadOS 17.0+ | 按设计支持 UIKit 的会话式亮度调整 | 待真机验证 |
| iOS 模拟器 | 禁用亮度写入，仍可构建及检查界面 | 不视作真机 |
| Mac／外接显示专用窗口 | 不提供亮度写入 | 不支持 |

Apple 官方接口：[UIScreen.brightness](https://developer.apple.com/documentation/uikit/uiscreen/brightness)。
SDK 属性读回验证的是系统 API 返回值，不能替代人工观察或光度测量。
读回比较允许约 0.4 个百分点的量化误差。应用前原值仅保留在会话内。

## 验收记录模板（全部待执行）

- [ ] 记录设备型号、系统版本、构建号与下载 IPA 的 SHA256；签名并安装。
- [ ] 记录「UIKit 当前读数」，选择差异至少 15 个百分点的目标值并确认写入。
- [ ] 新读数与目标匹配，真机显示亮度确实变化。
- [ ] 点「恢复原亮度」，新读数与原值匹配且显示效果恢复。
- [ ] 重复写入后将应用送入后台，返回后核对恢复结果。
- [ ] 在系统或用户另行调整亮度的情况下确认紫序不覆盖意外读数。
- [ ] 核对不支持的功能没有写入按钮或模拟操作。
