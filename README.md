# LilaShift 5.0.0 · 紫序 Apple 官方接口版

**可签名预发布构建 50000001。** 此分支是同一仓库的独立官方接口构建目标，不替换主分支、旧 IPA 或旧发行版。不包含沙盒逃逸、受保护系统文件写路径、私有 API、企业签名或远程自动发布。

- 内置屏幕亮度：会话内写入、UIKit 读回、手动恢复及后台恢复尝试。
- Apple 智能报告：有大小限制的离线 JSON 摘要，仅限选中文件。
- 资源监控：当前进程常驻内存、前台压力事件、监控会话时长与 RIPEstat 请求字节。
- 网络出口：仅用户确认后发起一次 RIPEstat HTTPS 查询。
- 壁纸工坊：本地双层构图，导出 1080 × 1920 静态 PNG；不更改系统壁纸。
- 浅色（默认）、深色、跟随系统；简中和英语。

未实现受保护 MobileGestalt、钱包/系统锁屏写入或设备自配对，未真机验证。最低 iOS/iPadOS 17.0。企业证书应由授权持有人本地签名；本文件不得冒充已签名分发版。

下载 CI 构件 ZIP，解压后校验 `shasum -a 256 -c LilaShift_5.0.0_Official_API.ipa.sha256`。源代码以 GPLv3 发布；紫序图标沿用本仓库既有素材。W7/W8/W9/W11 代码为本仓库独立实现，没有新增第三方源码或运行时依赖。

本地可执行 `swift test` 和 `bash scripts/package.sh`。仅使用 Xcode 标准 iOS SDK。
