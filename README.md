# LilaShift 5.0.0 · 紫序

**Apple 官方接口版 · 预发布候选 · Build 50000001**

本分支是独立的官方接口实现，不包含 4.x 的受保护系统访问代码、私有接口或第三方运行时依赖。此分支不替换 `main`，不删除旧标签、分支或发布资产。

| 功能 | 实际行为 |
| --- | --- |
| 屏幕亮度 | 读取内置屏幕当前亮度；用户确认后写入，并通过 UIKit 属性读回核对 |
| 亮度恢复 | 写入前保存会话原值；手动恢复或后台自动尝试恢复；只有读回匹配才报告恢复成功 |
| 设备信息 | 从设备读取系统版本、设备类别、物理内存和逻辑处理器数量 |
| 外观 | 浅色、深色、跟随系统；只影响紫序 |
| 语言 | 简体中文、英语 |

**不能改：** 受保护 MobileGestalt、eSIM 准入、Apple 智能资格、系统外观、钱包卡面、锁屏资源。没有用本地文件编辑或预览代替上述系统写入。没有集成十个候选项目的代码；Logo 沿用本仓库既有紫序图标。

## 安装及验证

- 编译目标为 iOS/iPadOS 17.0 及以上。屏幕写入仅面向有内置屏幕的真机，模拟器、Mac 不提供写入。
- IPA 未携带企业证书、描述文件或私钥；请使用与应用标识和目标设备相匹配的签名与配置，企业签名用于获准的组织内分发。
- 下载后在 IPA 和校验文件所在目录执行 `shasum -a 256 -c LilaShift_5.0.0.ipa.sha256`。
- 屏幕亮度属于会话变化，不会永久改写系统设置。强退可能中断自动恢复；Apple 说明下一次解锁时系统恢复原亮度设置。用户在控制中心调整后如读值不一致，本应用不会覆盖该值。恢复失败可以重试或通过控制中心手动恢复。

## 构建

在装有 Xcode 和 iOS SDK 的 macOS 上，运行 `swift test`，再运行 `bash scripts/package.sh`。CI 使用同一脚本，校验 IPA 结构、版本、架构及 SHA256。单元测试不代表真机已经验证。
